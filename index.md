# Data Science Project Materials

Source files and reproducible analyses for the three projects in the [portfolio website](https://mc66006.github.io/data-science-portfolio/).

- [Proposal 1 — Seattle rent and mixed-income housing](proposal1/): proposal, notebook, course-provided data, analysis script, and figures.
- [Proposal 2 — College tuition and earnings](proposal2/): revised proposal, notebook, College Scorecard extract, results, script, and figures.
- [Learning time and outcomes](learning-time-and-outcomes/): completed simulation exercise with synthetic data, analysis code, and figures.

Each project README explains its research question, data, methods, findings, limitations, and run instructions.
