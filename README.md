# Study Time, Tutoring, and Course Scores

**Project status:** Completed as a simulation-based demonstration.

## Research question

In a hypothetical student sample, how is focused weekly study time associated with final course scores, and how do the scores compare between students with and without tutoring?

## Dataset and permissions

This project uses a fully simulated dataset of 120 hypothetical students. It contains weekly study hours, a tutoring indicator, and a final score from 0 to 100. The data are generated by `src/analyze.py` with a fixed random seed and are also included as `data/study_hours_simulated.csv` for convenience. No real student records or personal information are used. The dataset is original synthetic content for this course demonstration; there is no third-party dataset license to claim.

## Methods and tools

Python, NumPy, pandas, and Matplotlib are used to generate the reproducible sample, summarize groups, and create three static visualizations. The scatterplot compares study hours with scores and displays the simulation's segmented average patterns. The boxplot compares score distributions by tutoring status. A binned mean plot compares the tutoring groups within study-hour bands and makes high-score differences easier to inspect.

## Key findings

In this simulated example, scores rise more quickly up to about 15 study hours per week and then rise more slowly. The tutoring group is generated with an approximately five-point score offset at the same study time. See the figures in `figures/` for the pattern and spread.

These are properties intentionally built into the simulated data. They are not empirical findings about real students, and the tutoring difference does not establish a causal effect.

## Visualization refinement

The analysis includes `figures/binned-score-comparison.png` to inspect scores for students studying at least 15 hours. Its upper panel compares group means with descriptive 95% confidence intervals on an explicitly zoomed 85–100 score axis; the lower panel shows the share reaching 100 and labels group counts. This is a visualization refinement. It should be described as a peer-feedback response only if the student can confirm the actual review and record it in the portfolio repository.

## Limitation

Because the data are synthetic and the generating relationship is known by construction, this exercise cannot establish how real study time or tutoring affects academic performance. The score ceiling also compresses differences among high scores. A real study would require appropriately authorized data, careful measurement, and adjustment for prior preparation, course difficulty, and other relevant factors.

## How to run

From the project root:

```bash
python -m pip install -r requirements.txt
python src/analyze.py
```

The script rewrites `data/study_hours_simulated.csv` and saves the visualizations to `figures/`.
